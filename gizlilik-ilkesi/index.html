Gizlilik ilkesi

Web sitemiz üzerinden paylaşılan bilgilerin korunmasına ilişkin esaslar.

Görüşme planlayın

ACR Bilgi Sistemleri olarak ziyaretçilerimizin gizliliğine önem veriyoruz. Bu Gizlilik İlkesi, www.acrbilgi.com üzerinden paylaşılan kişisel verilerin hangi amaçlarla işlendiğini, nasıl korunduğunu ve hangi durumlarda üçüncü kişilerle paylaşılabileceğini açıklamaktadır.

Web sitemizi ziyaret ettiğinizde veya iletişim formlarımızı kullandığınızda paylaştığınız bilgiler yalnızca hizmet sunmak, taleplerinizi değerlendirmek ve sizinle iletişime geçebilmek amacıyla kullanılmaktadır.

Kapsam

Bu politika aşağıdaki kişileri kapsamaktadır:

  • Web sitesi ziyaretçileri
  • Teklif talebinde bulunan kullanıcılar
  • Destek talebi oluşturan müşteriler
  • İletişim formunu kullanan ziyaretçiler

İşlenen veriler

Web sitemiz üzerinden aşağıdaki bilgiler işlenebilir:

  • Ad soyad
  • Firma adı
  • Telefon numarası
  • E-posta adresi
  • Talep veya mesaj içeriği
  • IP adresi
  • Tarayıcı ve cihaz bilgileri
  • Çerez (cookie) verileri

Verilerin kullanım amaçları

Toplanan bilgiler şu amaçlarla kullanılmaktadır:

  • Teklif taleplerinin değerlendirilmesi
  • Teknik destek süreçlerinin yürütülmesi
  • Müşteri ilişkilerinin yönetilmesi
  • Hizmetlerin geliştirilmesi
  • Web sitesi performansının analiz edilmesi
  • Kanuni yükümlülüklerin yerine getirilmesi

Saklama ve güvenlik

ACR Bilgi Sistemleri, kişisel verilerin güvenliğini sağlamak amacıyla güncel teknik ve idari güvenlik önlemleri uygular. Veriler:

  • Yetkisiz erişime karşı korunur
  • Güvenli sunucularda saklanır
  • Düzenli olarak yedeklenir
  • Gerektiğinde şifrelenerek muhafaza edilir

Çerez kullanımı

Web sitemizde kullanıcı deneyimini geliştirmek amacıyla çerezler kullanılabilir. Çerezler şu amaçlarla kullanılır: site performansını ölçmek, trafik analizleri yapmak, kullanıcı tercihlerini hatırlamak. Tarayıcı ayarlarınız üzerinden çerez kullanımını dilediğiniz zaman değiştirebilirsiniz.

Üçüncü taraf hizmetleri

Web sitemizde aşağıdaki üçüncü taraf hizmetleri kullanılabilir. Bu servisler kendi gizlilik politikaları çerçevesinde veri işleyebilir.

  • Google Analytics
  • Google Ads
  • Microsoft Clarity
  • reCAPTCHA

İletişim

Gizlilik politikamız hakkındaki sorularınız için info@acrbilgi.com adresinden bize ulaşabilirsiniz. Yasal saklama süreleri sona erdiğinde kişisel veriler güvenli yöntemlerle silinir veya anonim hale getirilir.
